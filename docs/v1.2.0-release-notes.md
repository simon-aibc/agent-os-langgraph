# Release Notes: v1.2.0 (Backend Portability)

This release resolves the core framework's tight coupling to hardcoded `claude` and `codex` binaries by introducing an explicit `BackendAdapter` protocol and a pluggable `BackendRegistry`.

## Highlights

- **Backend Portability:** The architect and executor subgraphs now resolve their targets dynamically through a `BackendRegistry`. Both the Claude Code and Codex implementations are now adapters behind this stable interface.
- **Diagnostics (`agent-os doctor`):** A new diagnostic command reports installed binaries, authentication status, and configured roles in human-readable and JSON output.
- **Profiles:** Added support for named configuration profiles via TOML, with inheritance and `[profile.local]` overrides.
- **Direct Escalation:** A new `ROUTER_MODE=direct-escalation` mode allows operators to skip Tier-2 structured routing when initiating an architect-first workflow.
- **Durable Backend Binding:** SQLite checkpoints now store the resolved backend configuration, ensuring that a resumed thread continues execution on the exact same provider it started with, even if environmental defaults change.

## Validation

- Passed 285 offline tests, treating all warnings as errors.
- Comprehensive smoke used the Claude Code CLI adapter for both architect and executor roles; Codex adapter coverage is verified by the offline test suite through the shared registry code path.
